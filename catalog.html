STAGE 06

Каталог публичных API

Двенадцать реальных API-сервисов, с которыми можно работать без бэкенда и почти без затрат. Используйте фильтр по категориям, чтобы найти сервис для своего мини-проекта.

Найдено сервисов: 12

Таблица 4. Двенадцать открытых API для практики
СервисКатегорияКлючCORSЧто умеет
JSONPlaceholderРазработкаНе нуженДаФейковый REST для прототипов: посты, задачи, пользователи
GitHub RESTРазработкаНе нужен*ДаРепозитории, профили, коммиты; с ключом лимиты выше
PokeAPIИгрыНе нуженДаЭнциклопедия покемонов: характеристики, спрайты, способности
Open LibraryДанныеНе нуженДаМиллионы книг: названия, авторы, обложки, ISBN
REST CountriesДанныеНе нуженДаСтраны мира: столицы, флаги, население, валюты
Cat FactsКонтентНе нуженДаСлучайные факты о кошках — работает в демо 7-й стадии
Dog CEOКонтентНе нуженДаФото собак по 90+ породам
TheMealDBКонтентТестовыйДаРецепты блюд с фото и пошаговыми инструкциями
Open-MeteoПогодаНе нуженДаТекущая погода и прогнозы по координатам, без регистрации
ExchangeRate-APIФинансыНе нужен*ДаКурсы валют; открытый эндпоинт обновляется ежедневно
CoinGeckoФинансыНе нужен*ДаЦены и статистика криптовалют (демо-лимит запросов)
Where the ISS at?КосмосНе нуженДаТекущие координаты МКС, обновление раз в секунду

* Сервис можно пробовать без ключа, но регистрация расширяет лимиты. Колонка «CORS» отвечает на вопрос: пустит ли сервер запросы прямо из браузера — если «нет», нужен сервер-прокси (см. 4-ю стадию).
