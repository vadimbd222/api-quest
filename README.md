
# API QUEST — учебный сайт об API-сервисах

URL: https://vadimbd222.github.io/api-quest/

Сайт на HTML5 + NES.css + нативном JavaScript по теме «Использование API-сервисов при разработке сайтов». Сайт сам работает как API-клиент: терминал на странице «Демо» отправляет настоящий fetch-запрос к открытому API catfact.ninja.

## Страницы

1. `index.html` — главная и выбор стадии
2. `api-basics.html` — что такое API
3. `rest-http.html` — REST и HTTP
4. `data-formats.html` — JSON и XML
5. `auth-keys.html` — ключи и токены
6. `frontend.html` — интеграция на фронтенде, видео
7. `catalog.html` — каталог 12 публичных API
8. `demo.html` — живой запрос к API
9. `glossary.html` — глоссарий
10. `about.html` — о проекте

## Запуск

Открыть index.html в браузере двойным кликом, или в терминале:

start index.html

## Стек

- HTML5, семантические `header/main/aside/footer`, таблицы с `caption` и `scope`
- NES.css через CDN
- CSS3: кастомные стили, Grid, Flexbox, адаптив (768/992px)
- Нативный JavaScript: хэш-роутер, бургер-меню, фильтр таблицы, fetch-запрос с подсветкой JSON, прогресс в localStorage
