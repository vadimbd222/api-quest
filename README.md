## О проекте
- **Дисциплина:** Современные веб-технологии
- **Тема (задание №10):** Использование API-сервисов при разработке сайтов
- **CSS-фреймворк (№13):** [NES.css](https://nostalgic-css.github.io/NES.css/) — ретро 8-битный CSS-фреймворк
- **Ссылка на репозиторий GitHub:** _вставьте сюда ссылку на ваш репозиторий_

Сайт состоит из 10 связанных страниц и рассказывает, что такое API, чем отличаются REST,
GraphQL и WebSocket, как устроена аутентификация, какими инструментами пользуются разработчики
и какие практики считаются хорошим тоном при работе с внешними сервисами.

## Технологии
- **HTML5** — семантическая вёрстка (`header`, `nav`, `main`, `aside`, `footer`, `figure`, `table`)
- **CSS3** — кастомные стили в `css/style.css`, названия классов по методологии **БЭМ**
- **NES.css** — CSS-фреймворк, подключён через CDN (`unpkg.com/nes.css`)
- **JavaScript (vanilla)** — `js/script.js`: бургер-меню, подсветка активного пункта меню,
  слайдер фактов в сайдбаре, модальное окно «О проекте», демо-обработка формы подписки

## Адаптивность
Вёрстка мобильно-ориентированная (mobile-first) с тремя контрольными точками:
- **до 768px** — одна колонка, бургер-меню
- **от 768px** — горизонтальное меню, сетка карточек в 2 колонки
- **от 992px** — двухколоночный макет «контент + сайдбар», сетка карточек в 3 колонки

## Запуск проекта локально
Проект не требует сборки и зависимостей — это статические файлы.
1. Скачайте/склонируйте репозиторий.
2. Откройте `index.html` в браузере, либо запустите локальный сервер, например:
   ```bash
   npx serve .
   # или
   python3 -m http.server 8000
   ```
3. Перейдите по адресу `http://localhost:8000`.

## Деплой на GitHub Pages
1. Загрузите содержимое папки `api-quest/` в корень репозитория на GitHub.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/root`, сохраните.
4. Через 1–2 минуты сайт станет доступен по адресу вида
   `https://<ваш-логин>.github.io/<название-репозитория>/` — вставьте эту ссылку в начало
   данного файла и в поле выше.
