О проекте

«API QUEST» — учебный проект по фронтенд-разработке на тему «Использование API-сервисов при разработке сайтов». Сайт не просто рассказывает про API — сам работает как API-клиент: лаборатория на 7-й стадии отправляет настоящие сетевые запросы.

Автор

Гарунов Вадим, группа 141-ПМо. Курс: «Фронтенд-разработка». Почта для связи: sss2905@pochta.com.

Стек технологий

  • HTML5 — семантическая разметка: header, nav, main, aside, article, figure, dl, таблицы с caption и scope.
  • CSS3 — кастомные стили в отдельном файле css/style.css: Grid, Flexbox, sticky, три контрольные точки (мобильные, ≥768px, ≥992px).
  • NES.css 2.6 — CSS-фреймворк в стиле 8-битных консолей.
  • Нативный JavaScript — в отдельном файле js/script.js: бургер-меню, загрузочный экран, фильтры, терминал fetch-запросов, прогресс в localStorage.
  • 10 отдельных HTML-страниц + страница 404, связанных обычными ссылками.
