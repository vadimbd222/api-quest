STAGE 07

Живая лаборатория

Единственная страница курса, где запрос уходит по-настоящему. Кнопки ниже обращаются к открытому API catfact.ninja прямо из вашего браузера, а терминал фиксирует всё: команду, HTTP-статус, время и тело ответа.

API-TERMINAL v1.0

// Нажмите GET /fact — терминал выполнит настоящий запрос
IDLE

Что происходит при нажатии

  1. Строка команды. В лог печатается адрес, к которому обратился fetch.
  2. Статус и время. Сервер отвечает кодом (200 или 404) — рядом видно, сколько миллисекунд занял путь туда-обратно.
  3. Тело ответа. JSON подсвечивается: ключи жёлтым, строки зелёным, числа голубым — как в DevTools.

Кнопка «ВЫЗВАТЬ 404» обращается к несуществующему пути специально: fetch вернёт ответ, но res.ok будет равен false — ровно тот случай, который мы учились обрабатывать на 5-й стадии.

Код, который стоит за терминалом

const res = await fetch('https://catfact.ninja/fact');
if (!res.ok) throw new Error('HTTP ' + res.status);
const data = await res.json();
// data = { fact: "…", length: 42 }

У сервиса есть rate limit (см. 4-ю стадию): если нажимать кнопки слишком часто, однажды придёт 429 — и это тоже поучительно.
